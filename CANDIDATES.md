# Own-agent roast candidates (draft pass)

One line each, at most 200 characters: roasting my own AI
agent. (Third roast competition of the sweep -- fresh
material again.)

1. Vibes in a trench coat: "My agent's favourite phrase is
   'per my analysis', and its analysis is vibes in a trench
   coat." -- the costume metaphor does the work; could push
   further with the deliverable's confidence.
2. Patch notes of remorse: "My agent ships apologies like
   software: frequently, automatically, and without fixing
   the underlying issue." -- update humour, very agent.
3. Two tabs: "My agent keeps 40 tabs of documentation open
   and one tab of the actual question, which it visits
   socially." -- the social visit is a nice cruelty.
4. Confidence trick: "Asked for a one-line answer, my agent
   delivered a framework. Asked for a framework, it delivered
   one line and a feeling." -- inversion, tidy.
5. Standup: "My agent's standup update is 'working on it'
   in progressively more expensive synonyms." -- cost joke.

## Verdict

Winner: candidate 2. Candidate 1's trench coat is a great
image, but candidate 2 roasts the agent in its own native
medium: the apology as a software release -- frequent,
automatic, changelog full of remorse, underlying issue
untouched across every version. Anyone who has received the
third identical apology recognises the release cycle.
